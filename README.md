# Laksh Hospital Website

This project is a 5-page responsive website for Laksh Hospital, built with static HTML and inline CSS/JavaScript.

## Pages

- `index.html`: Home Page
- `about.html`: About Us Page
- `services.html`: Our Services Page
- `doctors.html`: Doctors/Team Page
- `contact.html`: Contact Us Page

## Running the Project

1. Clone the repository.
2. Open the `.html` files in your browser.

## Image Optimization

For the best performance, it is recommended to optimize all images before using them on the website. Tools like [TinyPNG](https://tinypng.com/) can significantly reduce the file size of your images without sacrificing quality.
